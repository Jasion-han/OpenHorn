# Documentation Health Maintenance

保持 skills 目录不退化：文件不会过长、不会过碎、无断链、无重复内容。

## When to Run

- 完成 `update-rules.md` 后，快速检查修改过的文件行数
- 文件感觉"难以导航"或"太长不想读"时主动维护

## Size Reference

| 文件类型 | 参考范围 | 触发评估 | 碎片信号 |
|---------|---------|---------|---------|
| `SKILL.md` | ≤ 100 行 | > 100 行 | — |
| `rules/*.md` | 50–200 行 | > 200 行 | < 30 行 |
| `workflows/*.md` | 30–150 行 | > 150 行 | < 15 行 |
| `references/*.md` | 50–300 行 | > 300 行 | < 30 行 |

这些是**参考值**，不是硬阈值。单主题的长文件可以保持原样。

## Split/Merge Criteria

**拆分**：三个问题全部"是"才有价值：
1. 主题可分离？
2. 导航困难？
3. 每部分能独立站立（> 30 行）？

**合并**：三个问题全部"是"才有价值：
1. 主题相关？
2. 合并后更好找？
3. 合并后不超标？

## Reference Integrity Check

文件拆分、合并、重命名或删除后：
- [ ] SKILL.md 所有链接有效
- [ ] workflows 的 "Read First" 引用存在
- [ ] 无孤立文件、无重复内容
- [ ] 如文件被删除，无其他文件引用它
