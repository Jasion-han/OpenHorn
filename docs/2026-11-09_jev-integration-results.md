## 设置与费用

本机已配置并启用五个功能，默认**每日0.05美元/当前本地用户**，UTC零点进入新额度周期；总开关和各功能开关可在Agent设置修改。功能范围默认折叠。费用上限通过`OPENHORN_JEV_DAILY_BUDGET_USD`配置，Docker Compose也已接入相关环境变量。

预算先按当前模型默认请求上限保守预留，再按成功回执结算。没有账单回执的失败保留未确认额度，避免重启或超时反复消耗；账本保存在用户settings中。已确认费用、未确认额度和上限分别显示。预算不足不发新请求，已开始请求的真实账单高于预留时也会如实计入并阻止后续超额请求。

- 同用户/功能/相同payload合并请求，成功缓存10分钟，失败冷却60秒；缓存及冷却表有容量上限。共享请求的后续使用者计费为0，不重复累计账单。
- 默认超时5秒，影子路由2秒，覆盖HTTP响应体读取；没有自动付费重试。请求最多28KB和100个问题；评论根据实际JSON/UTF-8大小拆成最多6条的子包。
- API Key已存于Git忽略的`apps/server/.env`，文件权限0600；示例配置和Compose只有变量占位，不含Key。Key不进入普通设置响应或客户端。
- 子进程清理覆盖`OPENHORN*`、`OPENROUTER_API_KEY`和`TYPESAFE_API_KEY`。决策请求会遮蔽当前服务Key及常见`sk-…`/Bearer凭据模式，避免配置求助文本把凭据当语义内容发送；这不承诺能识别任意形式的秘密。
- 普通`NODE_ENV=test`禁用真实决策凭据，隔离测试仅在显式synthetic模式使用假Key/封闭fetch。测试预加载还主动移除开发者决策Key。

- **Server521、Desktop670、Shared66、Sidecar331、Adapters82，共1670项Bun测试通过，0失败。** 重点回归包括：typed形状/版本/概率校验、关闭/额度不足/超时不调用模型、并发与缓存计费、持久预算、凭据遮蔽、评论lost ACK/人工修改/删除、RAG来源在语义等待后失效、技能全名单和必需项保留。
