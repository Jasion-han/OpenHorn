# 放弃确认状态的一致性修复

## 问题与行为

继续审查现有表单后，发现资料上传已具备放弃确认守卫，但资料提问和成果版本编辑仍只检查提交锁/忙碌状态。确认区出现后，普通提交入口仍有机会准备问题或追加成果版本，成果草稿也会随保存被清除。

本次补齐两个入口：

- `LibraryQuestionDialog`：`discard` 为真时，提交函数立即返回；问题、模型和普通取消/准备操作禁用。继续编辑后保留问题内容和原有重试请求身份。
- `ArtifactPanel`：`confirmDiscard` 为真时，`saveVersion` 立即返回；正文、格式、保存和普通取消操作禁用。继续编辑后保留草稿，正常保存仍携带原来的 `expectedVersion`，不改变版本协议。

只修改这两个组件及四项真实处理函数回归，没有新增依赖、接口或模型调用。成果切换时已有的确认状态重置逻辑保留。
