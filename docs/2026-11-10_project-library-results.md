# 项目资料库交付记录

已启用侧栏原有“资料库”入口，完成上传与原件保留、索引状态/重建、个人/项目关键词检索、正文与片段查看、原件下载、带来源的聊天草稿、问答历史，以及原生备份恢复与统一搜索定位。

上传、索引与检索均不调用模型。提问准备只创建普通Chat会话与可编辑草稿（autoSend:false），由用户发送后调用所选模型。支持PDF及UTF-8文本/Markdown/CSV/JSON/常见代码；首版为关键词检索，不含语义向量召回或扫描PDF OCR，合成流程验证不代表模型答案准确率。

页面复用现有字体、色彩和间距；只常驻范围、检索和导入，其他操作收进更多。模型设置默认折叠，放弃在当前窗口内确认。草稿按账号/后端/范围在内存中暂存，离开页面可恢复；换账号或重启清理。下载在原生保存调用前再次核验身份，取消不冒称成功。

## 数据与边界

- SQLite新增library_documents/library_chunks/library_questions，Drizzle与bootstrap同步；原件、抽取文字和索引有界，原件不可变。单个5MiB、每用户50MiB原件/100资料、单份2MiB正文/1000片段、合计25MiB正文、PDF100页；持久化标题字段限制280字符，防止重复长标题放大存储。
- 用户与项目隔离；去重/配额在SQL事务内，唯一键兜底。本进程队列降低SQLite竞争，忙时整事务有界重试；索引完成/失败用revision/token CAS，解析不持长事务，过期索引可重建。
- 问答最多5个完整片段，完整JSON UTF-8预算24KiB；问题最多500字符、最多200条记录，可删除记录回收名额而保留聊天。requestId与输入指纹匹配才复用，先查幂等记录再检索。来源冻结后不随资料变化；缺会话不自动新建，缺项目保留不可用原范围。
- 共用data-only helper隔离Review与Library的记忆、其他附件RAG、实时路由和GenUI追加。无来源不创建会话；写入前拒绝无效/非所属/禁用模型及ACP。
- 备份包含原件与问答账本，不包含可重建片段/临时租约；校验Base64编码长度/规范、解码大小与SHA。项目范围字段必须一致，按用户重绑后重新派生scopeKey；缺项目资料明确跳过，问答保留不可用范围，重复恢复幂等。ZIP限实际解压字节并拒绝重名entry。
