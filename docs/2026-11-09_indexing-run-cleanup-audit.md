# 文档索引与后台取消检查

本轮修复四类可以隔离复现的问题，沿用现有页面和定时任务模式。

| 问题 | 实测与修复 |
|---|---|
| 超长单段突破文档分块上限 | 一万字符的单段仍生成一个大块；段落拼接与Markdown长节也会超限。现在每块最多2800个UTF-16代码单元，优先段落/行/词边界，保留约200字符重叠；分块及重叠边界避免拆开Unicode代理对，连续索引和标题归属保留 |
| 首次并发建向量表冲突 | 临时真实LanceDB中6个文档同时写入，旧实现5个失败、只保留1个。现在同实例共享连接与建表Promise；其他实例先建表时打开已有表，不覆盖；失败释放Promise以便重试。验证并发6个全部保留、两个独立实例、连接失败恢复，以及删除后再追加不恢复已删数据 |
| 后台超时漏取消迟到运行 | 超时时还没有sidecar运行编号，旧逻辑之后收到编号也不取消。现在记住取消意图，编号到达后补发取消；超时/失败后的事件不能改写消息，迟到审批明确拒绝。正常完成回调先于投影done事件时仍正确保存completed状态，正常成功不额外取消 |
| 特殊设置键名丢失 | `__proto__`等键在普通对象映射时无法完整往返；现在设置结果使用无原型字典，特殊键为自有字符串属性，JSON往返保留。没有将字符串键丢失描述为已证实的原型污染漏洞 |

- 超时和启动失败的迟到ACK均用合成sidecar验证；注入后续文字、done与审批，确认取消只发一次、失败内容保持、没有批准工具。
- 工作台25、聊天异常56，共81个浏览器检查点通过，串行脚本均正常退出。
- 全仓类型、Biome格式检查及macOS debug app构建通过。测试只使用独立SQL数据库、临时向量目录和合成接口，不调用真实embedding或运行真实定时任务。

## 边界

分块限制不是精确token预算；不会自动修复历史向量或重算旧文档。本轮保持原向量路径、模型与维度。取消RPC为尽力请求，不能保证断网时已启动工具立即停止；本地消息和审批的终态保护独立生效。向量生命周期测试覆盖同进程独立连接/实例，不构成跨主机调度承诺。

新版桌面构建已生成，本轮未重启当前桌面会话或本地服务，后台取消修复需桌面重启后加载，服务端修复需重启服务加载。未Git提交、推送或外部部署。真实数据核对时为345个会话、2条任务、0条启用；本轮开始时344个会话，期间新增记录未被回滚或清理，不推断来源。
