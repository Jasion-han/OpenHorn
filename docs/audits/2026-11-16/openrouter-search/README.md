## 接入结果

- 搜索连接使用独立Key；OpenRouter固定`deepseek/deepseek-v4-pro`、官方接口、Exa引擎。与Jev及当前回答模型的凭据分开。主列表只读服务端已验证活动目录，去重后展示；两种DeepSeek协议只保留一个入口，未配置/未验证类型放入显式配置入口。
- 当前无修改、无待验证替换时显示禁用的“已启用”，避免重复付费验证；已删除重复的当前模型/引擎段落。
- 当前目录未发现专用DeepSeek搜索模型，端点未声明原生工具；`:online`是已弃用的联网包装，不构成DeepSeek官方原生搜索转发证明。采用已实测的`openrouter:web_search`协议并明确标注搜索引擎。
- 候选与活动配置均加密，保存不切换；显式验证要求完整回答及结构化公共引用，普通模型回答不能启用。验证前后比较revision，迟到请求不替换新配置。
- Chat前置检索、SSE、桌面发送/编辑/重试/后台以及direct/Claude Agent Search接通。关闭联网不加载检索凭据，Stop贯穿请求；无自动付费重试或切换来源。
- 检索摘要明确标为模型生成，推理、签名及密钥不进入回答上下文。Agent Fetch可安全读取页面原文且不向网页发送OpenRouter Key；服务端Chat保留原有链接读取门控，不以搜索摘要冒充原文。
