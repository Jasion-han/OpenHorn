## 最终行为

- 单一来源选择器并列 Tavily、DeepSeek 原生联网、DeepSeek 搜索接口、DuckDuckGo；顶部持续显示实际生效来源。取消底部高级原生覆盖开关。
- 原生联网使用独立官方 Key 或符合条件的官方 Pro 渠道，固定 `https://api.deepseek.com/v1/responses` 与 `deepseek-v4-pro`，显示凭据、模型和接口来源。GPT/Claude 仍负责回答，使用自己的回答凭据。
- 保存候选配置不会切换来源；仅主动“验证并启用”才发起可能计费的请求，检索调用、成功计数及结构化来源满足条件才激活。一次请求可能触发多个服务端搜索操作；失败不自动重试付费检索或切换来源。
- 普通聊天、编辑、重试、后台任务及两种 Sidecar Search 路径传播同一独立检索契约。DeepSeek 模型摘要明确为检索摘要；不传递私有状态、推理、签名或检索 Key 给其他回答模型。
- 补齐准备/上传阶段 Stop、跨挂载所有权与延迟取消失败提示。停止后的上传失败仅保存问题和附件元数据并说明上传未确认，不声称文件已上传。
