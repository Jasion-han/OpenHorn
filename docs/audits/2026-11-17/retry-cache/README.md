## 已复现并修复

- **研究重试覆盖旧报告**：只有工具进度、没有新正式报告的失败、停止和空结束，以前会替换原成功报告。现在恢复原报告且不覆盖原服务端行；普通 Agent 的工具/文件操作记录保持原停止语义。
- **过期的重试策略**：原生测试中，关闭 Web Search 后，缓存的消息回调仍按旧允许联网状态执行。回调只按消息 memo 化，而联网和 Full Access 会在之后改变。重试和编辑重发改为点击时读取当前会话与权限设置，并在准备期间保留研究标记。真实组件夹具改用产品的会话更新接口，覆盖两种开关方向与完整保存时序。
- **技术 URL 误作引用**：代码示例中的 API 地址被当作来源检查，且代码中单独出现来源地址可能被误当作有效引用。采用与现有 Markdown 渲染一致的 micromark 代码边界，排除行内、围栏和缩进代码中的 URL；正文仍须有实际检索到的来源，代码外编造链接继续拒绝。新增反例在旧代码上失败、修复后通过。未留存被拒绝的原始模型报告全文，不把所有历史失败武断归因为这一项。
- **缓存容量与清理**：六张各 1 MiB 的图像在 Base64 和 JSON 编码后超过旧 8 MiB 单条限额。单条改为 12 MiB，账户仍 50 MiB、7 天；cursor 逐条计量与删除过期快照，不批量加载所有账户图像。超过额度不驱逐未过期快照，读取过期的本账户条目会回收它。打开/事务失败统一为可恢复的 document_cache。
- **上传异常回执**：校验已知 PDF/图片的 MIME 类型与非空字段，畸形成功 JSON 也走可恢复错误；原文件和草稿走既有恢复流程。保留未标类型及旧 image/jpg 的服务端 MIME 推断兼容性。
- **输入和操作反馈**：研究回车发送与按钮使用相同前置门控，避免旧运行时创建无效回合和重复通知；操作栏默认浅色低对比可见，避免刚从隐藏显现时首击丢失。单次模型超时、总期限、空报告、输出截断和引用失败使用不同结构化提示。
