# 工作台次要操作默认收起

用户指出上一轮常驻功能键仍然过多，要求能收起的收起。本轮以该纠正为准，替代此前编辑/历史/导出直接展示的布局选择，已重新构建、重启桌面端，当前停在默认收起的配方页。

| 页面 | 默认主要操作 | 按需展开 |
|---|---|---|
| 配方 | 运行一次、更多 | 编辑、历史、任务详情、项目/模型绑定、暂存与定时说明、创建定时任务、删除 |
| 成果 | 继续修改、更多 | 编辑、导出、原文/预览、版本选择、来源、重命名、删除；编辑期间只展示编辑所需操作 |
| 评论 | 项目选择、选中计数、一个主按钮及相应更多入口 | 导入/刷新/导出/删除、筛选、分析方式与模型设置、分析记录 |

评论未选择时，主按钮只在本地选择下一批；选中后显示当前分析动作，必须再次点击才准备聊天或运行 Jev。切换分析方式不发送请求。未配置模型/Jev 等阻塞原因仍可见，失败提示和草稿保护不因收起而隐藏。历史、导出、来源和定时管理能力均保留，参数暂存及单层放弃确认保持。

验证：675 项桌面 Bun 测试通过；60 个浏览器检查点通过（工作台32、评论20、Jev8），覆盖默认隐藏/展开后的完整操作、先选择再分析、单层确认、版本冲突、历史与原文字节导出、预算失败/迟到响应、窄屏和深浅主题。`pnpm typecheck`、`pnpm check`、macOS debug app 构建通过。

原生实际查看了配方/成果的默认界面，并展开菜单确认次要功能均可访问；菜单关闭后返回配方默认页。未修改真实配方、运行任务、导入真实评论或新增付费联通探针。应用正常启动遵循已有功能配置。
