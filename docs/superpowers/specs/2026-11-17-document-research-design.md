# PDF 图文输入与深度研究

用户在核对 DeepSeek 应用能力吸收情况后授权补充值得加入的后续功能。本轮落实能与当前多模型渠道配合使用的 PDF 图文输入和受约束的网页研究，不重新配置用户 Key，不自动提交或发起真实收费请求。

## 实现选择

- 文档可直接接 DeepSeek Files API（Office/PDF 的 `rich_layout_recognition`，需要官方账户，远端解析不可下载），或本地 PDF.js 渲染页面。采用后者作为本轮可交付范围：现有视觉模型可直接理解页面，复用真实图片附件。Office 仍走现有显式 OCR；不声称已完成官方 Files API 或所有格式的图文解析。
- 实际上传回归复现 Hono 默认丢失同名文件以及 Bun 1.3.10 `formData()` 在二进制 NUL 处截断（含真实 loopback HTTP）。因此用 `busboy` 替代上传解析，新增该运行库、`streamsearch` 传递依赖及类型声明，不修改 Bun 本身。请求总64MiB、单文件20MiB、20个文件和16个短字段有界；拒绝重复作用域。客户端核对回执数量/名字/大小/ID，旧后端不完整回执不能启动模型。
- 研究可依赖厂商私有深度搜索，或使用应用现有搜索/网页读取与模型工具调用。采用后者，保持当前有效搜索源，API 型 OpenAI/Anthropic/Google 通过现有 adapter 执行。CLI/ACP/OAuth 运行方式不声称支持该模式，入口给出可操作提示。
- 保留现有 Chat/Agent 数据模式；深度研究作为 Agent 的显式配置，用 `/research` 标记发起，模式菜单提供入口。已保存回合记录研究标记，重试按该回合标记执行，不受当前输入框设置影响。

## PDF 输入

- 默认文字读取；附件区每个 PDF 提供显式「读取图表」选项与页码范围。仅视觉模型可用，非视觉模型不能静默丢图。
- 页码从 1 开始，支持逗号及闭区间，去重排序。空范围表示全文，但全文超出限制时拒绝并要求选择，不静默截取。每次发送最多 6 个 PDF 页面，每图最多 1 MiB、总图最多 6 MiB，长边最多 1600px；原件仍遵守现有附件上限。
- 页面在本地渲染成 JPEG，保留原 PDF，派生图片使用原文件名和实际页码命名。Chat 上传并持久化原件和真实页面图片；Agent 复用图片附件通道。消息显示实际发送页面，不伪装成用户上传了未知文件。
- 所有页面先解析成功再交付；解析/页码/大小失败时保留草稿与原文件、不发模型请求。Stop 取消渲染并销毁 PDF worker/document，不清除较新的草稿。
- 文件选项仅在本次登录内按 File 对象保留，欢迎页移交同一 File 时保留，切换账户清空；不用全局磁盘设置保存私有文件。
- Agent 图文输入生成的完整附件 parts 写入按服务端与账户隔离的 IndexedDB 恢复缓存，消息只保存随机引用。重试读取原输入；缓存缺失或不可写明确失败并要求重新附加，不能只凭文件名继续。缓存最多保留7天、单条12MiB、当前账户50MiB；12MiB 包含六张上限图像的 Base64、JSON 及文字开销。用 cursor 逐条统计并清理过期数据，不批量载入所有账户图像；额度不足不驱逐未过期快照。Chat 使用已有服务端真实附件持久化。
- 渲染前就保存 `documentInputRequired`，即使提前Stop导致快照未生成，重试也必须要求重新附加，不能变成无附件普通回合。派生图片预览按File身份与展开上传顺序对齐。

## 深度研究

- 模式菜单显式选择研究，输入保留原问题；联网关闭时拒绝发起并提示开启，不暗改联网开关。
- 本轮研究只接受问题与文字历史，附件需先在 Chat/Agent 中图文分析；有附件时阻止研究发送并说明，不静默忽略。PDF 图文与研究分别为完整独立流程，不承诺本轮研究支持图像。
- 新研究执行器调用现有 API adapters，工具只有 `web_search` 和 `web_fetch`；不挂载 MCP、skills、shell、文件写入或旧 SDK 会话。用户显式 `/server` 与研究互斥，不能借组合指令绕过工具范围。
- 沿用当前已激活搜索连接与独立凭据；不切换来源、不新增付费自动重试。实际来源由执行分支记录。
- 最多4个唯一搜索请求、6个唯一 URL 读取任务、12轮模型工具决策，失败也占预算；供应商内部搜索次数、重定向与 Markdown 读取不是外层预算计数，不把它宣传为最大计费操作数。相同规范化查询/URL复用本轮结果。180秒包含报告整理，工具阶段预留最多30秒整理；用户Stop或总期限到达时直接中断，不触发额外整理。
- 成功证据须从工具实际返回的结构化来源取得，并区分检索摘要与读取原文；来源回调、空结果和错误字符串不算成功。最终报告的来源清单由实际证据生成，不从模型正文推断。无原文时明确未核对原文。
- 重试保留研究模式，每次尝试使用发起时当前激活搜索连接、记录本次实际来源；不继承旧尝试证据或私有凭据。菜单说明重试使用当前搜索源。
- 已有成功报告的研究重新生成，必须等新正式报告产生后才替换旧报告；只有工具进度时，失败、停止或空结束均恢复原报告，不覆盖服务端原记录。普通 Agent 的工具/文件执行记录继续按原停止规则保存。报告式决策可等待最多60秒，但仍服从180秒总时限；区分单次模型超时、报告为空、输出截断与引用无效。
- 研究可规划、搜索、交叉核对原文、整理。必须至少成功搜索后再给研究报告；无可用来源明确失败，不把纯模型回答称为完成研究。工具输出作为不可信引用数据，报告要求真实来源 URL 与未核实项。
- 每轮按实际上下文预算检查，保留工具请求/结果配对；取消中断搜索、Fetch、模型与报告整理，晚到事件不写入后续回合。工具进度与原始结果沿用现有步骤持久化；不虚构费用和 token 数。

## 验证与交付

使用合成 PDF（文字、图形和扫描页）、受控搜索与模型工具回合，测试范围错误、总页数、取消、非视觉模型、非 API 渠道、错误来源、重复工具、预算、来源持久化和重试。跑相关 Bun 测试、类型、Biome、UI/Sidecar 构建，实际打开桌面检查浅色菜单、选择/取消、文档选项和研究入口。真实模型请求与付费解析若未执行，报告准确区分。原有 WIP 保留，只清理本轮临时数据。
