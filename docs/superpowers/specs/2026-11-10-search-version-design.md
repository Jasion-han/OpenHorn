# 统一搜索与版本对比恢复

依据用户对推荐前两项的确认，复用左上角搜索和已有历史区域。其余资料库、最近删除、文件成果、会话分支不在本轮实现范围。保持主操作加更多，任务内容仍为默认关闭的页面折叠行。

统一搜索为关键词查询，不调用模型：会话标题/消息正文、当前成果标题/正文、配方名称/说明/任务模板、项目名、评论项目名。后端统一校验用户，输入最多200字符，每类最多8条；不返回历史工具日志、凭据配置或未经授权数据。结果分组、点击定位；防抖、旧请求丢弃、空查询清理、失败重试保持。已删除对象点击给出明确反馈，不创建任务。

配方和成果的历史区域按需对比所选版与当前版；全文相等先判断，大文本超过有界行比较预算时显示有明确截断提示的两份原文。差异只作为转义文本展示，不执行HTML。配方对比覆盖完整spec，而非仅提示词。

恢复必须显式确认sourceVersion/expectedVersion；服务端从用户拥有的不可变历史读内容，再沿现有CAS管线追加新版本。原版本保留，已有定时快照不变，配方引用重查。成果恢复以保存的历史原文为准，不重新读取可能变化/已删除的源消息，新增版本使用独立副本的中性来源。并发冲突/加载失败保留当前查看内容并允许重试；迟到响应不得切换用户正在查看的对象、清掉草稿或跨账号应用。

不增加依赖或数据库字段。原始历史/备份格式兼容。测试使用隔离数据库、假接口和合成数据；不恢复真实用户对象作为验收。
