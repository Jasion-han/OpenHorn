# 工作台操作衔接优化

用户已确认依次实施上一轮评估的五项调整。沿用现有三页布局：任务配方、已保存成果、评论分析；执行时间、启停与记录仍由定时任务页管理。

- 成果续改：仅在续改创建的目标会话中预选原成果，收藏时明确显示追加目标/源版本，仍需用户保存；允许另存。目标已删除或加载失败不静默新建。绑定和参数仅在当前后端/登录会话的内存中保留，不跨账号。
- 评论分析：聊天分析区域包含模型选择、准备按钮和“需发送并回来同步”说明；Jev 区域说明直接标注情感/主题，不生成说明，不依赖聊天模型。无数据时只显示一个导入入口。删除移入独立更多菜单。
- 配方：按 ID 和版本暂存填写内容及选择，页签/页面往返可恢复；版本变化采用新参数默认值，旧值不跨版本套用。增加只读历史窗口，加载/失败可重试，历史不自动替换当前内容或改变定时快照。
- 名称：保留任务配方，描述明确为可复用任务模板；产物用户文案统一为成果，页签为已保存成果。

实现选择：使用现有 Zustand 内存状态、现有详情/版本 API 和现有 Dialog。无需增加数据库字段、自动执行或新的一级入口；持久化会引入过期任务/跨账号风险，故不采用。校验成果关联、人工保存、配方跨版本/登录隔离、空态和两种分析方式的区别。
