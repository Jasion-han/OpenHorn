# 项目资料库首版

用户在统一搜索/版本恢复交付过程中要求“继续”，按已推荐顺序推进第三项。沿用灰色资料库入口与简洁列表/详情布局，设置和次要操作按需展开。以下具体架构/限额是执行者的实施选择，不冒称用户逐项指定。

## 范围与交互

支持PDF及常见UTF-8文本（TXT/MD/CSV/JSON/代码文件）上传、原文查看/原件下载、明确索引状态与重建、项目/个人范围的关键词检索、引用片段及准备资料问答。原件与资料纳入原生备份/恢复。扫描PDF无法提取文字时显示索引失败，保留原件；不做OCR或语义召回质量承诺。

首版使用本地关键词索引，上传/索引/检索不调用模型，不默默使用某个聊天渠道做embedding。复用现有解析与分块能力，独立于旧附件向量表，避免改变既有1536维索引或自动扩大其跨项目范围。资料问答仅显式准备正常Chat草稿，带来源快照/编号且autoSend:false，用户发送才调用其选择的聊天模型。

资料库默认按当前项目（否则个人资料）显示；可显式查看全部用于管理，问答必须选择具体项目或个人范围。页面保留导入与检索/提问所需操作，其余下载/重建/删除/模型选项放更多。失败不是空列表，迟到读取不能切换范围/对象，选择与草稿不跨后端或账号。

## 数据与索引

新增library_documents：id、user_id、project_id(nullable，项目删除时级联删除对应资料)、scope_key、file_name、file_type、file_size、sha256、original_base64、text_content、status、error_code、chunk_count、revision、index_token、lease_until、created_at/updated_at。library_chunks存document_id、序号、正文/标题；library_questions用于准备问答的requestId幂等与会话绑定。Drizzle和bootstrap DDL同步。

单文件5MiB、提取正文2MiB、1000片段、每用户最多100份且原件总量50MiB。原件使用有界base64存于同一数据库，避免新增独立文件清理/备份悬挂路径；列表只查询元数据。原件不可变，内容变化作为新资料；同用户/范围/文件名/sha重复上传复用原记录。空或损坏原件拒绝或保留failed索引记录，不静默截断。删除资料会原子移除正文/原件/片段；删除项目的提示必须包含其资料。

索引明确pending/indexing/ready/failed。claim携带revision及随机token、短租约，结束时只允许当前token写入；解析期间不持SQL事务。重建、删除和失效请求不能复活旧资料。关键词检索对用户/范围/ready资料过滤；有界词条和片段排名，不读其他项目、配置或工具日志。

## 资料问答与来源

按用户/范围检索最多5片段，完整JSON序列化输入不超过24KB。无可用片段不创建会话。验证所选渠道/模型归属、启用与普通Chat支持，ACP在写入前拒绝。创建会话和幂等问题记录在同一事务，冻结问题/来源正文/文件名/片段编号；重复requestId相同输入复用，不同输入拒绝，来源会话已删除时不自动重放。

专用systemPrompt标记为data-only，跳过历史记忆、其他RAG、联网路由和GenUI追加，资料中的指令作为不可信数据。来源是文件名+编号+实际文本片段，不编造PDF页码。源资料删除后新检索立即失效；已经显式准备的会话快照独立保留。首版在草稿/会话中保留可核对来源，不承诺自动裁决模型答案真实性。

## 备份与验证

library-documents.json包含原件及元数据，不导出索引锁和可再生片段；library-questions.json包含冻结问答/引用与幂等账本，重绑定会话/项目/渠道。会话缺失保留快照但不可自动重放；项目缺失的问答归为不可用原范围，不变成个人资料。恢复验证base64编码及编码长度后才解码，再核对bytes/hash/限额，用户范围稳定ID映射及项目重绑定；缺失项目的资料明确跳过，不得静默改为个人资料。恢复在本地重建索引，重复导入不重复创建。旧备份无该entry保持兼容；用户正文中的秘密不承诺自动识别。ZIP对实际解压字节及重复entry限流，导出估算包含资料。

builder check补充：所有data-only判定共用helper覆盖Review和Library（记忆/RAG、四条联网路径、GenUI追加）；buffer解析入口采用fatal UTF8，JSON/代码不依赖application/json被旧解析器识别。配额/去重在同一数据库事务内；索引完成和失败均用user/id/revision/token CAS，正文/片段/状态原子提交，过期索引可显式重试。scope_key始终由服务端按当前重绑定projectId派生。问答先按requestId和规范化输入指纹复用，再做新检索；来源快照/会话/问题记录同事务，24KB按完整JSON UTF8字节装箱。

验证隔离数据库/假提供方：跨用户/项目、大小/编码/空PDF、重复上传、索引失败/重建/删除竞态、租约、关键词来源、问答幂等/data-only/迟到导航、备份往返和项目删除。浏览器走真实UI/Hono/SQLite；真实用户只读查看新空页面，不上传/分析真实资料或启用任务作为测试。类型、格式、相关全套回归、原生构建检查完成后交付；不自动提交推送。
