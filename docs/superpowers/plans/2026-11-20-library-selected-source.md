# 资料库选中片段提问

1. 在 `PrepareLibraryQuestionInput` 增加可选 `source`，由 `documentId`、`chunkIndex`、`revision` 标识。服务端在原事务内按用户、个人或项目范围和当前就绪版本读取该片段，生成单一来源快照。范围问答沿用原请求指纹，片段问答将完整引用纳入指纹。
2. 在 `LibraryView` 的命中片段旁提供提问入口。全部资料视图使用命中资料的归属范围。`LibraryQuestionDialog` 展示文件名和位置，区分片段与范围草稿，复用现有模型选择和手动发送流程。
3. 扩展现有隔离库和浏览器测试。检查第二个片段、无关键词问题、跨账号与范围、过期引用与快照重试。实际检查按钮焦点、弹窗和聊天草稿。
