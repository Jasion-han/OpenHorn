# 后台请求与设置同步检查

本轮确认并修复四类问题，重点是错误数据、失败重试和异步响应覆盖。沿用现有页面布局，没有新增功能入口。

| 问题 | 修复后的行为 |
|---|---|
| 向量接口直接按返回顺序配文本，缺少数量和维度检查 | 按响应 index 对齐输入；拒绝重复/混合/越界 index、数量不符及非1536维有限数向量。兼容完全省略 index 的服务。默认15秒超时覆盖请求和响应体读取，辅助接口支持传入取消信号 |
| 欢迎推荐生成失败后每次读取都可能再调用模型 | 同用户并发去重，失败或空结果后冷却60秒；继续返回旧缓存，不阻塞页面。保留现有12小时TTL和缓存seed，避免升级时无故重算 |
| 欢迎推荐旧响应/定时器在重置后回写 | 身份变化重置缓存、清理定时器，并用请求代次忽略旧结果；旧请求的finally不能清除新请求；启动时等待身份加载后再读取推荐，避免身份重置清掉刚加载的结果 |
| Agent设置重连覆盖未保存Key，加载与写入互相覆盖 | 首次加载前禁止编辑；失败显示重试；重连更新基线并保留当前草稿；保存中禁止重复操作；失败保留Key草稿、恢复搜索开关；切页后旧保存成功会触发当前页面重新加载 |

实现及回归位于`embeddingService.ts/.test.ts`、`welcomeSuggestionService.ts/.test.ts`、`welcomeSuggestionStore.ts/.test.ts`和`AgentSettings.tsx`；UI复查使用`node apps/desktop/scripts/settings-clarity.browser.mjs`。
