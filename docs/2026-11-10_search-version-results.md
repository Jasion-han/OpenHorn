# 统一搜索与版本对比恢复

已按用户确认完成推荐的前两项，并更新本地服务与桌面端。默认页面继续保留简洁布局，任务内容仍在页面上默认折叠。

## 使用方式

- 左上角放大镜现在是统一搜索，按会话、消息、成果、配方、项目、评论项目分组。会话标题/消息正文、当前成果正文、配方说明与任务模板、项目及评论项目名称可匹配。每类最多8条，达到上限时提示缩小关键词。关键词查询不调用模型；消息结果打开所属会话，首版不滚动到指定消息。
- 成果和配方从更多进入历史，选旧版后展开“与当前版本对比”。差异只作为文本展示，较大的变更切换为有界原文视图，超出展示长度会明确说明。配方比较完整配置；成果比较正文，格式仍可从版本记录查看。
- 点击恢复后先显示将从哪版另存为哪版，确认才追加。成果恢复完整历史正文/格式，标题与项目仍为当前元数据；配方恢复完整spec。源消息变化或删除不影响成果历史恢复。已有历史和定时快照保持原样。

并发更新使本次恢复失败，不覆盖新内容；刷新当前版本后必须重新确认。恢复完成前跳到其他成果、新建会话、切换身份或离开页面，迟到响应不会改写新界面的选择或清掉新草稿。已接受的服务端恢复不会因离开页面自动撤销。
